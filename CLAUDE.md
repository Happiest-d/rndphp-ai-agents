## Описание проекта

Это презентация для доклада "Pest'датый фреймворк для тестирования" на RnD PHP митапе. Проект использует Shower HTML Presentation Engine с кастомной темой rndphp.

## Структура проекта

- `index.html` - основной файл презентации с контентом слайдов
- `shower/` - движок презентаций Shower
  - `shower/themes/rndphp/` - кастомная тема для RnD PHP
- `pictures/` - изображения для слайдов
- `package.json` - npm зависимости и скрипты для управления презентацией

## Команды разработки

### Локальная разработка
```bash
npm install           # Установка зависимостей
npm run serve        # Запуск локального сервера для разработки
```

### Создание финальной версии
```bash
npm run prepare      # Создает чистую копию презентации в папке prepared/
npm run archive      # Создает archive.zip с только необходимыми файлами
npm run pdf          # Генерирует PDF версию презентации
```

### Публикация
```bash
npm run publish      # Публикует презентацию онлайн
```

## Архитектура Shower

Shower - это HTML презентационный движок. Презентации создаются как обычные HTML файлы с использованием специальной разметки:

- Каждый слайд представлен тегом `<section class="slide">`
- Модификаторы слайдов: `preview`, `clear`, `black`, `gray`
- Элементы слайдов: `shout` (большой заголовок), `cover` (фоновое изображение)
- Навигация: стрелки, пробел для перехода между слайдами
- Режимы просмотра: `list` (список всех слайдов) и `full` (полноэкранный режим)

## Особенности темы rndphp

Кастомная тема содержит:
- Специальные стили для брендинга RnD PHP
- Кастомные шрифты PT Sans и PT Mono
- Графические элементы: полосы, линии, фоновые изображения
- Специальные модификаторы для первого слайда
